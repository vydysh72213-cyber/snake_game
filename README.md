# Snake Game in C++

A simple terminal Snake game. Collect apples, grow your tail, and score points. Avoid the walls and your own tail.

## Run

```bash
g++ snake_game.cpp -o snake_game
./snake_game
```

## Controls

- `W` / `A` / `S` / `D` — move up, left, down, and right.
- `Q` — quit.

Enter a key and press Enter to make a move.
